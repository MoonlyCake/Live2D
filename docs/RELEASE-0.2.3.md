# 0.2.3 — 透视桌前鲸鱼娘

- 使用批准的新鲸鱼娘桌前构图：默认700×458，大透视键盘在前景，左手握鼠标、右手按键。83个物理键独立显示；指尖与键帽共用透视坐标，真实对应最近仍按住的键。
- 工作姿态停留4秒再淡回全身，窗口边界固定。保留五种基本工作眼口表情，以及全身五表情、眨眼、作息、偷吃和被发现收碗。
- 锁定时自动点击穿透，可点到下面的窗口；从菜单栏/托盘或面板解除锁定即可恢复拖动与交互。
- 改善授权后回到面板的输入恢复，并提供“重新连接键鼠”。重要状态说明使用更清楚的文字。

本版生产输入组件仍为既有uiohook；独立Rust实验没有启用或混入安装包。云端Linux实测重连后收到真实系统按键，但macOS辅助功能权限、密码输入保护和跨版本授权仍有系统限制，不能承诺所有监听中断均已根治。程序不重置系统权限，也不记录输入内容。

模型是官方Creator导出的Inochi INP，采用本项目支持的格式子集，不是Cubism MOC3。全身42层44实参、工作27层20实参。192应用测试、31解析/光栅测试、80吃饭打断状态及Linux实际24动作截图通过。Apple芯片Mac与Windows的最终原生结果以本次CI报告为准。CPU后备不承诺30/60帧；Mac为ad-hoc签名，非Developer ID公证。

第三方完整许可、Electron/Chromium声明与可重建原生输入源码继续包含。没有实现自动更新或更新下载按钮。
